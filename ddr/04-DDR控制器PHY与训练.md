# DDR 控制器、PHY 与训练

DDR 内存系统的可靠运行离不开控制器、PHY（物理层）以及训练机制的协同工作。本章详细介绍 DDR 控制器的内部架构、PHY 的组成与功能，以及 DDR 训练的完整流程——从写均衡、读写门控训练到 Vref 校准，帮助读者理解高速信号完整性保障的关键技术。

### 1.3 DDR 训练

#### 1.3.1 为什么需要训练

```
DDR 训练的目的:

问题:
├── PCB 走线长度差异 → 信号到达时间不同
├── 芯片工艺差异 → 延迟不一致
├── 温度变化 → 延迟漂移
└── 电源波动 → 时序抖动

解决:
└── DDR 训练 → 动态调整延迟，补偿差异
```

#### 1.3.2 训练流程

```
DDR 训练序列:

1. 写均衡 (Write Leveling)
   ├── 目的: 调整 DQS 与 CK 的相位对齐
   ├── 方法: DDR 芯片反馈 DQS 边沿
   └── 结果: 找到最佳 DQS 延迟

2. 读训练 (Read Training)
   ├── 目的: 调整 DQS 采样点
   ├── 方法: 读取已知模式数据，检查错误
   └── 结果: 找到最佳采样相位

3. 写训练 (Write Training)
   ├── 目的: 调整写数据与 DQS 的对齐
   ├── 方法: 写入并回读，检查错误
   └── 结果: 找到最佳写延迟

4. MPR 训练 (Multi-Purpose Register)
   ├── 目的: 精细调整读数据眼图
   ├── 方法: 使用 DDR 内置模式寄存器
   └── 结果: 优化每个 DQ 位延迟

5. Vref 训练
   ├── 目的: 调整参考电压
   ├── 方法: 扫描 Vref 值，找到最佳范围
   └── 结果: 最大化数据眼图开口
```

#### 1.3.3 训练结果示例


#### 1.3.4 DDR 训练完整流程详解

```
DDR 训练序列 (完整步骤):

┌─────────────────────────────────────────────────────────────┐
│  阶段1: 初始化准备                                            │
├─────────────────────────────────────────────────────────────┤
│  1. 配置时钟 PLL，等待锁定                                    │
│  2. 配置 DDR 控制器基本参数                                   │
│  3. 释放 DDR 复位信号                                         │
│  4. 等待时钟稳定 (通常 >200μs)                                │
│  5. 使能 CKE，进入正常模式                                    │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段2: Write Leveling (写电平训练)                           │
├─────────────────────────────────────────────────────────────┤
│  目的: 补偿 DQS 和 CK 之间的传输延迟差异 (Skew)               │
│  原因: PCB 走线长度不同，导致 DQS 和 CK 到达 DDR 的时间不同   │
│                                                              │
│  方法:                                                       │
│  1. 控制器发送 Write Leveling 命令                            │
│  2. DDR 进入 Write Leveling 模式 (MR1 设置)                   │
│  3. 控制器发送 DQS 信号 (固定电平)                            │
│  4. DDR 采样 DQS 边沿，通过 DQ 反馈结果                       │
│  5. 控制器调整 DQS 延迟，直到收到反馈翻转                     │
│  6. 记录最佳延迟值                                            │
│                                                              │
│  结果: DQS 与 CK 在 DDR 端对齐                                │
│                                                              │
│  时序示意:                                                   │
│  训练前: CK ────┐  ┌─┐  ┌─┐                                 │
│                 └─┘  └─┘  └─┘                                │
│         DQS ────────┐  ┌─┐  ┌─┐  (延迟较大)                   │
│                     └─┘  └─┘  └─┘                            │
│                                                              │
│  训练后: CK ────┐  ┌─┐  ┌─┐                                 │
│                 └─┘  └─┘  └─┘                                │
│         DQS ────┐  ┌─┐  ┌─┐  (对齐)                          │
│                 └─┘  └─┘  └─┘                                │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段3: Read/Write Gate Training (读写门控训练)               │
├─────────────────────────────────────────────────────────────┤
│  目的: 确定 DQS 窗口的起始和结束位置                          │
│                                                              │
│  Read Gate Training:                                         │
│  1. 控制器发送 READ 命令                                      │
│  2. DDR 返回已知数据模式 (如 MPR 数据)                        │
│  3. 控制器扫描 DQS 延迟，找到能正确读取的范围                 │
│  4. 设置 Read Gate 起始位置                                   │
│                                                              │
│  Write Gate Training:                                        │
│  1. 控制器发送 WRITE 命令                                     │
│  2. 写入测试数据                                              │
│  3. 回读验证                                                  │
│  4. 调整 Write Gate 延迟                                      │
│                                                              │
│  结果: 确定 DQS 有效窗口 [Start, End]                         │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段4: DQ Training / 2D Training (数据线训练)                │
├─────────────────────────────────────────────────────────────┤
│  目的: 找到每个 DQ 位的最佳采样点 (眼图中心)                  │
│                                                              │
│  1D Training (仅延迟扫描):                                   │
│  ├── 固定电压，扫描延迟                                       │
│  ├── 找到延迟有效窗口                                         │
│  └── 设置延迟为窗口中心                                       │
│                                                              │
│  2D Training (延迟 + 电压扫描):                               │
│  ├── 扫描延迟 (X轴) 和电压 (Y轴)                              │
│  ├── 绘制二维眼图                                             │
│  ├── 找到眼图中心 (最大裕量点)                                │
│  └── 设置最佳延迟和电压                                       │
│                                                              │
│  方法:                                                       │
│  1. 使用 MPR (Multi-Purpose Register) 产生已知数据模式        │
│  2. 对每个 Byte Lane 独立训练                                 │
│  3. 对每个 DQ 位独立调整                                      │
│  4. 记录 Pass/Fail 区域                                       │
│                                                              │
│  2D 眼图示意:                                                │
│  电压                                                        │
│   ▲                                                          │
│   │   FFFFFFFFFFFFFFF                                        │
│   │   FPPPPPPPPPPPF   ← 眼图区域                             │
│   │   FPPPPPPPPPPPF      (P=Pass, F=Fail)                    │
│   │   FPPPPPPPPPPPF                                          │
│   │   FPPPPPPPPPPPF   ★ = 最佳采样点                         │
│   │   FPPPPPPPPPPPF                                          │
│   │   FPPPPPPPPPPPF                                          │
│   │   FFFFFFFFFFFFFFF                                        │
│   └──────────────────────► 延迟                              │
│                    ★                                         │
│                                                              │
│  结果: 每个 DQ 位的最佳延迟和电压值                           │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段5: CA Training (命令/地址训练)                           │
├─────────────────────────────────────────────────────────────┤
│  目的: 确保命令/地址总线信号质量                              │
│  适用: DDR4 及以上 (DDR3 通常不需要)                          │
│                                                              │
│  方法:                                                       │
│  1. DDR 进入 CA 训练模式                                      │
│  2. 控制器发送已知命令/地址模式                               │
│  3. DDR 通过 DQ 反馈采样结果                                  │
│  4. 控制器调整 CA 延迟                                        │
│  5. 找到最佳 CA 采样点                                        │
│                                                              │
│  训练信号:                                                   │
│  ├── CS# (片选)                                              │
│  ├── CA[0:17] (命令/地址)                                    │
│  └── 与时钟 CK 的相位关系                                     │
│                                                              │
│  结果: CA 总线可靠采样                                        │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段6: Vref Training (参考电压训练)                          │
├─────────────────────────────────────────────────────────────┤
│  目的: 调整 DQ 和 CA 的参考电压 Vref                          │
│  原因: Vref 偏差会导致采样错误                                │
│                                                              │
│  方法:                                                       │
│  1. 扫描 Vref 电压范围 (如 0.5VDD ~ 0.7VDD)                  │
│  2. 在每个 Vref 值下测试读写                                  │
│  3. 找到 Vref 有效窗口                                        │
│  4. 设置 Vref 为窗口中心                                      │
│                                                              │
│  Vref 扫描示意:                                              │
│  Vref                                                        │
│   ▲                                                          │
│   │   FFFFFFFFFFFFFFF                                        │
│   │   FPPPPPPPPPPPF   ← Vref 有效窗口                        │
│   │   FPPPPPPPPPPPF      中心 = 最佳 Vref                    │
│   │   FPPPPPPPPPPPF                                          │
│   │   FFFFFFFFFFFFFFF                                        │
│   └──────────────────────►                                   │
│                                                              │
│  结果: 最佳 Vref 值 (DQ Vref 和 CA Vref)                      │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段7: 验证和最终配置                                        │
├─────────────────────────────────────────────────────────────┤
│  1. 应用所有训练结果 (延迟、电压)                             │
│  2. 配置模式寄存器 (MR0~MR7)                                  │
│  3. 执行预充电所有 Bank                                       │
│  4. 执行自动刷新 (8次或更多)                                  │
│  5. 使能自动刷新                                              │
│  6. 运行内存测试验证                                          │
│  7. 保存训练结果 (到 Flash 或 OTP)                            │
└─────────────────────────────────────────────────────────────┘
```

#### 1.3.5 训练结果保存与复用

```
训练结果保存:

为什么需要保存:
├── 每次上电都训练会延长启动时间
├── 训练结果在温度变化不大时基本稳定
└── 保存后可跳过训练，快速启动

保存位置:
├── SPI Flash (Bootloader 区域)
├── eMMC/SD (特定分区)
├── OTP (One-Time Programmable) 熔丝
└── SoC 内部 SRAM (带电池备份)

保存内容:
├── Write Leveling 延迟值 (每个 Byte Lane)
├── Read Gate 延迟值
├── DQ 延迟值 (每个 DQ 位)
├── CA 延迟值
├── Vref 值
└── 训练时间戳和温度

复用策略:
├── 冷启动 (首次): 完整训练
├── 热启动 (温度变化 <10°C): 使用保存结果
├── 温启动 (温度变化 10~30°C): 部分训练 + 微调
└── 定期校准: 每隔一定时间重新训练
```
