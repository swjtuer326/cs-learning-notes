## 二、Zephyr RTOS 简介

Zephyr RTOS 是由 Linux 基金会托管的开源实时操作系统，专为资源受限的嵌入式设备设计。

| 特性 | 说明 |
|-----|------|
| **轻量级** | 最小可运行在 8KB RAM 的设备上 |
| **可扩展** | 支持从传感器到网关的各种场景 |
| **安全性** | 内存保护、用户空间隔离 |
| **开源** | Apache 2.0 许可证 |

## 四、核心组件概览

### 4.1 线程管理

| 概念 | 说明 |
|-----|------|
| **线程控制块** | `struct k_thread`，存储线程所有信息 |
| **优先级** | 数值越小优先级越高，负数为协作式，非负为抢占式 |
| **状态** | 就绪、运行、阻塞、终止 |

详细内容：[07_线程状态迁移详解.md](./07_线程状态迁移详解.md)

### 4.2 调度机制

| 策略 | 特点 |
|-----|------|
| **协作式** | 线程主动让出 CPU |
| **抢占式** | 高优先级线程抢占低优先级 |
| **时间片** | 同优先级线程轮流执行 |

详细内容：[08_调度策略详解.md](./08_调度策略详解.md)

### 4.3 同步机制

| 机制 | 用途 |
|-----|------|
| **信号量** | 资源计数、线程同步 |
| **互斥锁** | 互斥访问，支持优先级继承 |
| **条件变量** | 等待条件满足 |

详细内容：[05_同步机制详解.md](./05_同步机制详解.md)

### 4.4 内存管理

| 类型 | 特点 |
|-----|------|
| **静态分配** | 编译时确定，确定性 |
| **堆分配** | 灵活，可能碎片 |
| **内存池** | 固定大小块，无碎片 |

详细内容：[03_内存管理.md](./03_内存管理.md)

### 4.6 设备树

设备树将硬件描述从内核源码中分离，实现硬件与驱动的解耦。

```
.dts 源文件 ──dtc编译──► .dtb 二进制 ──解析──► 设备节点
```

详细内容：[02_设备树详解.md](./02_设备树详解.md)

## 六、快速参考

### 常用 API

```c
// 线程
k_thread_create()    // 创建线程
k_thread_start()     // 启动线程
k_thread_suspend()   // 挂起线程
k_thread_resume()    // 恢复线程
k_sleep()            // 线程睡眠

// 同步
k_sem_take()         // 获取信号量
k_sem_give()         // 释放信号量
k_mutex_lock()       // 锁定互斥锁
k_mutex_unlock()     // 解锁互斥锁

// 调度
k_yield()            // 让出 CPU
k_sched_lock()       // 锁定调度器
k_sched_unlock()     // 解锁调度器
```

