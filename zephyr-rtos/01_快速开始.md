## 5分钟快速上手

本指南帮助你在5分钟内完成 Zephyr 开发环境的搭建并运行第一个应用。

---

## 1. 环境准备

### 1.1 系统要求

| 组件 | 最低要求 | 推荐配置 |
|-----|---------|---------|
| 操作系统 | Windows 10 / Linux / macOS | Ubuntu 22.04 LTS |
| 内存 | 4GB | 8GB+ |
| 磁盘空间 | 10GB | 20GB+ |
| Python | 3.10+ | 3.11+ |

### 1.2 安装依赖

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install --no-install-recommends git cmake ninja-build gperf \
  ccache dfu-util device-tree-compiler wget \
  python3-dev python3-pip python3-setuptools python3-tk python3-wheel \
  xz-utils file make gcc gcc-multilib g++-multilib libsdl2-dev libmagic1
```

**Windows (使用 Chocolatey):**
```powershell
choco install cmake ninja gperf python git dtc-msys2 wget unzip
```

**macOS:**
```bash
brew install cmake ninja gperf python3 ccache qemu dtc wget
```

## 2. 安装 Zephyr SDK

### 2.1 下载并安装 SDK

```bash
# 创建安装目录
mkdir ~/zephyr-sdk
cd ~/zephyr-sdk

# 下载 SDK (以 v0.16.5 为例)
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v0.16.5/zephyr-sdk-0.16.5_linux-x86_64.tar.xz

# 解压
tar xvf zephyr-sdk-0.16.5_linux-x86_64.tar.xz

# 运行安装脚本
cd zephyr-sdk-0.16.5
./setup.sh
```

### 2.2 安装 Python 依赖

```bash
pip3 install --user -U west
```

---

## 3. 获取 Zephyr 源码

```bash
# 创建工作目录
mkdir ~/zephyr-project
cd ~/zephyr-project

# 初始化 west 并获取源码
west init -m https://github.com/zephyrproject-rtos/zephyr.git --mr v3.6.0

# 更新所有模块
west update

# 导出 Zephyr CMake 包
west zephyr-export

# 安装 Python 依赖
pip3 install --user -r ~/zephyr-project/zephyr/scripts/requirements.txt
```

---

## 4. 编译并运行第一个应用

### 4.1 编译 Hello World

```bash
# 进入 Zephyr 目录
cd ~/zephyr-project/zephyr

# 编译 Hello World 示例 (使用 QEMU 模拟器)
west build -p auto -b qemu_x86 samples/hello_world
```

**预期输出:**
```
-- west build: generating a build system
Loading Zephyr default modules (Zephyr base).
...
[1/1] Linking C executable zephyr/zephyr.elf
```

### 4.2 运行应用

```bash
# 在 QEMU 中运行
west build -t run
```

**预期输出:**
```
*** Booting Zephyr OS build v3.6.0 ***
Hello World! qemu_x86
```

🎉 **恭喜！** 你已经成功运行了第一个 Zephyr 应用！

## 5. 创建自己的应用

### 5.1 应用目录结构

```
my_app/
├── CMakeLists.txt    # 构建配置
├── prj.conf          # 项目配置
└── src/
    └── main.c        # 主程序
```

### 5.2 创建应用文件

**CMakeLists.txt:**
```cmake
cmake_minimum_required(VERSION 3.20.0)

# 查找 Zephyr 包
find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})

# 定义项目
project(my_app)

# 添加源文件
target_sources(app PRIVATE src/main.c)
```

**prj.conf:**
```
# 启用控制台
CONFIG_CONSOLE=y
CONFIG_UART_CONSOLE=y

# 启用 GPIO (如果需要)
CONFIG_GPIO=y
```

**src/main.c:**
```c
#include <zephyr/kernel.h>
#include <zephyr/sys/printk.h>

#define SLEEP_TIME_MS   1000

int main(void)
{
    printk("My First Zephyr Application!\n");

    while (1) {
        printk("Running...\n");
        k_msleep(SLEEP_TIME_MS);
    }

    return 0;
}
```

### 5.3 编译并运行

```bash
# 编译应用
west build -p auto -b qemu_x86 ~/my_app

# 运行
west build -t run
```

## 6. 常用 west 命令速查

| 命令 | 说明 |
|-----|------|
| `west build` | 编译当前项目 |
| `west build -p auto` | 自动清理并重新编译 |
| `west build -b <board>` | 指定目标板卡 |
| `west build -t run` | 编译并运行 |
| `west flash` | 烧录到硬件 |
| `west debug` | 启动调试器 |
| `west update` | 更新所有模块 |
| `west list` | 列出所有模块 |

## 常见问题

### Q: 编译时提示找不到 Zephyr 包？
A: 确保已运行 `west zephyr-export`，并检查 `ZEPHYR_BASE` 环境变量是否设置正确。

### Q: QEMU 无法启动？
A: 确保已安装 QEMU 并在 PATH 中。Ubuntu: `sudo apt install qemu-system-x86`

### Q: 如何查看支持的板卡列表？
A: 运行 `west boards` 查看所有支持的板卡。
