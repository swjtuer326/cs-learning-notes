# reference — 一手来源登记

本目录存放 Kimi K3 专题的一手规范(技术报告/论文),作为正文事实来源。正文数值与章节引用以此为准;查不到出处的内容在正文标"待确认"。

| 文件 | 内容 | 来源 |
|---|---|---|
| `kimi-k3-arxiv-2607.24653.pdf` | **Kimi K3: Open Frontier Intelligence**(47 页,技术报告) | arXiv 2607.24653v2 |
| `kimi-linear-arxiv-2510.26692.pdf` | **Kimi Linear**(KDA/Kimi Linear Attention 出处,报告 §2.1.1 细节 defer) | arXiv 2510.26692 |
| `attention-residuals-arxiv-2603.15031.pdf` | **Attention Residuals**(AttnRes 出处,报告 §2.2 defer) | arXiv 2603.15031 |
| `kimi-k3.txt` | 主报告 pdftotext 提取文本(grep 辅助,非一手) | 由 `kimi-k3-arxiv-2607.24653.pdf` 生成 |

下载方式:本环境 WebSearch 被拒,改用 arXiv export API + curl 下载。官方 spec 站(非 arXiv)自动下载常被 WAF/付费墙拦,必要时请用户浏览器手动下载放本目录。
